# ROS 2 Jazzy in WSL

This guide installs **ROS 2 Jazzy** on **Ubuntu 24.04 running inside WSL 2**.

ROS 2 Jazzy officially supports Ubuntu 24.04 (Noble).

All commands below are **WSL/Linux commands** unless marked otherwise.

---

# 1. Open Ubuntu 24.04

From **PowerShell**:

```powershell
wsl -d Ubuntu-24.04
```

Verify Ubuntu:

```bash
lsb_release -a
```

You should see:

```text
Ubuntu 24.04
```

Verify WSL is version 2 from **PowerShell**:

```powershell
wsl --list --verbose
```

---

# 2. Update Ubuntu

Inside Ubuntu:

```bash
sudo apt update
sudo apt upgrade -y
```

---

# 3. Set the locale

Run:

```bash
sudo apt install -y locales
sudo locale-gen en_US en_US.UTF-8
sudo update-locale LC_ALL=en_US.UTF-8 LANG=en_US.UTF-8
export LANG=en_US.UTF-8
```

Check:

```bash
locale
```

You should see UTF-8 in the output.

---

# 4. Enable the Ubuntu Universe repository

```bash
sudo apt install -y software-properties-common
sudo add-apt-repository universe
```

---

# 5. Add the ROS 2 repository

Install `curl`:

```bash
sudo apt update
sudo apt install -y curl
```

Download the current ROS 2 repository configuration:

```bash
export ROS_APT_SOURCE_VERSION=$(curl -s https://api.github.com/repos/ros-infrastructure/ros-apt-source/releases/latest | grep -F "tag_name" | awk -F'"' '{print $4}')
```

Then:

```bash
curl -L -o /tmp/ros2-apt-source.deb "https://github.com/ros-infrastructure/ros-apt-source/releases/download/${ROS_APT_SOURCE_VERSION}/ros2-apt-source_${ROS_APT_SOURCE_VERSION}.$(. /etc/os-release && echo ${UBUNTU_CODENAME:-${VERSION_CODENAME}})_all.deb"
```

Install it:

```bash
sudo dpkg -i /tmp/ros2-apt-source.deb
```

---

# 6. Install ROS 2 Jazzy

Update the package list:

```bash
sudo apt update
```

Install the desktop version:

```bash
sudo apt install -y ros-jazzy-desktop
```

Install the development tools:

```bash
sudo apt install -y ros-dev-tools
```

---

# 7. Load ROS 2

Run:

```bash
source /opt/ros/jazzy/setup.bash
```

Check that ROS works:

```bash
ros2 --version
```

Also try:

```bash
ros2 topic list
```

---

# 8. Automatically load ROS 2

You normally do not want to run `source` manually every time.

Add it to your Bash configuration:

```bash
echo "source /opt/ros/jazzy/setup.bash" >> ~/.bashrc
```

Reload:

```bash
source ~/.bashrc
```

Now open a new WSL terminal and check:

```bash
ros2 topic list
```

---

# 9. Create a colcon workspace

Create the workspace:

```bash
mkdir -p ~/ros2_ws/src
cd ~/ros2_ws
```

Source ROS:

```bash
source /opt/ros/jazzy/setup.bash
```

---

# 10. Create a minimal Python package

Move into `src`:

```bash
cd ~/ros2_ws/src
```

Create a package:

```bash
ros2 pkg create --build-type ament_python tmr_test --dependencies rclpy std_msgs
```

Check it:

```bash
ls
```

You should see:

```text
tmr_test
```

---

# 11. Build the workspace

Go back to the workspace:

```bash
cd ~/ros2_ws
```

Build:

```bash
colcon build
```

If successful, you should see:

```text
Summary: 1 package finished
```

Source your workspace:

```bash
source install/setup.bash
```

---

# 12. Test ROS 2 with a publisher and subscriber

ROS 2 includes example publisher/subscriber nodes.

Open **WSL Terminal 1**:

```bash
source /opt/ros/jazzy/setup.bash
ros2 run demo_nodes_cpp talker
```

You should see messages being published.

Keep this terminal running.

---

## 13. Start the subscriber

Open a **second WSL terminal**.

Run:

```bash
source /opt/ros/jazzy/setup.bash
ros2 run demo_nodes_py listener
```

You should see messages similar to:

```text
I heard: [Hello World: ...]
```

This verifies that a ROS 2 publisher and subscriber can communicate.

---

# 14. Test the topic directly

You can also inspect the topic from a third WSL terminal:

```bash
source /opt/ros/jazzy/setup.bash
ros2 topic list
```

You should see:

```text
/chatter
```

Then:

```bash
ros2 topic echo /chatter
```

You should see the published messages.

---

# 15. Verify your workspace package

Check that ROS can find your package:

```bash
source ~/ros2_ws/install/setup.bash
ros2 pkg list | grep tmr_test
```

You should see:

```text
tmr_test
```

---

## Done

You now have:

```text
Windows
└── WSL 2
    └── Ubuntu 24.04
        └── ROS 2 Jazzy
            └── ~/ros2_ws
                └── src/
                    └── tmr_test/
```

And you have verified ROS communication using:

```text
publisher → /chatter → subscriber
```

This is the basic communication model we will build on later in the course.
