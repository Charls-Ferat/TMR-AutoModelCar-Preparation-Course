# PyTorch + CUDA in WSL

This guide installs **PyTorch with NVIDIA GPU support inside WSL**.

> **Important:** Do not blindly copy a CUDA/PyTorch command from an old tutorial. PyTorch's supported CUDA builds change over time. Use the official PyTorch selector to obtain the current installation command for your machine.

All commands in this file, except where explicitly marked **Windows PowerShell**, are run inside **Ubuntu/WSL**.

---

# 1. Check your NVIDIA GPU — Windows

Open **PowerShell** and run:

```powershell
nvidia-smi
```

You should see information about your NVIDIA GPU and driver.

Look for something similar to:

```text
NVIDIA GeForce ...
Driver Version: ...
CUDA Version: ...
```

If `nvidia-smi` is not recognized:

* Make sure your computer has an NVIDIA GPU.
* Install/update the NVIDIA Windows driver.
* Restart Windows.
* Run `nvidia-smi` again.

---

# 2. Check the GPU from WSL

Open Ubuntu/WSL:

```powershell
wsl
```

Then, inside WSL:

```bash
nvidia-smi
```

You should see your NVIDIA GPU.

You can also run:

```bash
/usr/lib/wsl/lib/nvidia-smi
```

If the GPU appears here, WSL can access the NVIDIA GPU.

---

# 3. Check your WSL version

From **PowerShell**:

```powershell
wsl --list --verbose
```

Your Ubuntu distribution must show:

```text
VERSION
2
```

If necessary:

```powershell
wsl --set-version Ubuntu-24.04 2
```

---

# 4. Understand the CUDA version shown by `nvidia-smi`

Inside WSL:

```bash
nvidia-smi
```

You may see:

```text
CUDA Version: 13.x
```

This does **not** mean that you must install exactly that CUDA version.

The number reported by `nvidia-smi` indicates the CUDA level supported by the installed NVIDIA driver. PyTorch provides its own CUDA-enabled binaries.

For this course, the important question is:

> Which CUDA build does the current PyTorch installation selector support for my Linux/WSL environment and NVIDIA driver?

---

# 5. Check the NVIDIA driver

Run:

```bash
nvidia-smi
```

Record:

```text
GPU model
Driver Version
CUDA Version
```

Do not install an NVIDIA Linux display driver inside WSL.

The NVIDIA Windows driver provides GPU access to WSL.

---

# 6. Choose the PyTorch installation

Open the **official PyTorch "Start Locally" / installation selector**.

Choose:

* **PyTorch Build:** Stable
* **Your OS:** Linux
* **Package:** Pip
* **Language:** Python
* **Compute Platform:** the CUDA version currently supported for your system

The selector will generate the installation command.

### Example

The command may look similar to:

```bash
pip3 install torch torchvision torchaudio --index-url <current-pytorch-index>
```

**Do not use this example as a permanent command.**

Copy the command currently generated by the official PyTorch selector.

---

# 7. Prepare Python inside WSL

Inside Ubuntu:

```bash
sudo apt update
sudo apt install -y python3 python3-pip python3-venv
```

Check Python:

```bash
python3 --version
```

Check pip:

```bash
python3 -m pip --version
```

---

# 8. Create a PyTorch virtual environment

Create a directory:

```bash
mkdir -p ~/tmr-ml
cd ~/tmr-ml
```

Create the environment:

```bash
python3 -m venv .venv
```

Activate it:

```bash
source .venv/bin/activate
```

You should now see something similar to:

```text
(.venv) student@computer:~/tmr-ml$
```

Upgrade pip:

```bash
python -m pip install --upgrade pip
```

---

# 9. Install PyTorch

With the virtual environment active, run the **current command from the official PyTorch selector**.

For example, if the selector gives you:

```bash
python -m pip install torch torchvision torchaudio ...
```

copy and run that exact command.

Do not install a separate NVIDIA Linux driver.

---

# 10. Verify PyTorch

Inside the activated virtual environment:

```bash
python
```

Then run:

```python
import torch

print("PyTorch:", torch.__version__)
print("CUDA available:", torch.cuda.is_available())
print("CUDA version used by PyTorch:", torch.version.cuda)
```

For a GPU-enabled installation, you want:

```text
CUDA available: True
```

You can also check the GPU name:

```python
print("GPU:", torch.cuda.get_device_name(0))
```

Exit Python:

```python
exit()
```

---

# 11. One-command verification

You can also run:

```bash
python -c "import torch; print('PyTorch:', torch.__version__); print('CUDA available:', torch.cuda.is_available()); print('CUDA:', torch.version.cuda); print('GPU:', torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'None')"
```

A successful installation should produce something similar to:

```text
PyTorch: 2.x.x
CUDA available: True
CUDA: 12.x
GPU: NVIDIA GeForce ...
```

The exact versions will depend on the current PyTorch release and your system.

---

# If CUDA is not available

Run these commands and check each step:

```bash
nvidia-smi
```

```bash
python -c "import torch; print(torch.cuda.is_available())"
```

```bash
python -c "import torch; print(torch.version.cuda)"
```

Then check:

1. WSL is version 2.
2. `nvidia-smi` works inside WSL.
3. Your Windows NVIDIA driver is current.
4. You selected **Linux + Pip + Python + CUDA** in the official PyTorch selector.
5. You installed the command generated by the current selector.
6. Your virtual environment is activated.

If `nvidia-smi` does not work in WSL, fix the WSL/NVIDIA setup before troubleshooting PyTorch.

---

## Important: CUDA Toolkit

For normal PyTorch installation, **do not automatically install the full CUDA Toolkit just because you see "CUDA" in PyTorch**.

PyTorch's prebuilt CUDA packages include the components needed to run PyTorch.

A separate CUDA Toolkit is mainly relevant when you need to compile CUDA programs or CUDA extensions.
